# 验证说明

## 自动化

当前完整测试：**104 项通过，0 失败，0 跳过**。命令：

```sh
npm test
```

测试依赖 Node.js 23+、anvil 和原生 Solidity 0.6.x solc，使用临时目录、模拟钥匙串及模拟币安接口。链上测试只连接本地测试链，不读取真实登录或支付主网 gas。

主要覆盖：

- 账户会话、密钥、缓存、操作和固定设备档案的隔离。
- 预期钱包校验、重复钱包拒绝、预览绑定、错误账户隔离。
- 聚合兑换、受限授权、合约事件和业务结果核验。
- 提交结果不明、持久化意图、幂等、重启恢复与链重组。
- 批次预算、固定账户选择、并发预占、暂停恢复和部分结果。
- 账户元数据、完整历史快照、预览不计为参与和摘要去敏。
- 网页同源、Host、CSRF、受限 API 与只读 RPC 独立代理。

## 浏览器

```sh
npm install --global playwright
npm run test:web
```

使用本地 Google Chrome、隔离网页服务和模拟账户，验证：

- 总览与真实接口形状的历史数据展示。
- 账户改名、HTML 字符转义、归档与恢复。
- 按账户筛选项目、交易详情与链上链接。
- 新增账户、二维码显示、配对状态和登录完成。
- CSRF 拒绝、移动布局及页面脚本错误。

默认 Chrome 路径适配 macOS，其他环境可通过 `CODEX_CHROME_EXECUTABLE` 指定。浏览器测试不访问真实币安登录。
